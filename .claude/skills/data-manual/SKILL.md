# 데이터 매뉴얼 스킬

이 레포의 데이터 작업은 **docs/DATA-MANUAL.md가 정본**이다. 이 스킬은 그 문서를 반드시 읽게 하는 포인터다.

1. 먼저 `docs/DATA-MANUAL.md` 전체를 읽는다. 특히 §1 원칙, §6 검증 체크리스트, §9 함정.
2. 현황은 `docs/data/MASTERS-INDEX.md`, 분담은 `docs/COLLAB-DATA-TAEHUI.md`.
3. 절차 번호(§3→§4→§5→§6→§7→§8)대로 진행하고, **새 접근을 시도하지 않는다.**
4. 수치는 출처에서만. 확실하지 않으면 `"미검증"` 표시 후 멈추고 사용자에게 묻는다.
5. 끝나면 §14 완료 정의로 자기 점검 → MASTERS-INDEX 갱신 → 작업 브랜치에서 PR.

도구는 `scripts/binran/`(便覧 PDF) 과 `scripts/`(시라버스 크롤). 실행법은 각 README.
