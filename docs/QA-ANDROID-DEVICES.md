# 안드로이드 실기기 QA 체크리스트

> 작성 2026-10-25 · 대상: **안드로이드 실기기** (태희 보유 4대)
> 왜 필요한가: 준희는 iPhone만 있어 **안드로이드 실기기 검증이 0건**이다.
> 웹 미리보기로는 **키보드·내비바·터치**를 검증할 수 없다(RN Web ≠ 네이티브).

## 0. 설치 방법

안드로이드 production 빌드는 아직 없다(EAS는 iOS 빌드 2·3만). 두 경로 중 하나:

| 경로 | 명령 | 비고 |
|---|---|---|
| **Expo Go (지금 가능)** | `npx expo start --tunnel` → QR | 가장 빠름. 과거 폰 검증도 이 방식 |
| APK | `eas build -p android --profile preview` | 준희 Expo 계정 필요. production에 더 가까움 |

> Expo Go는 production 빌드와 **완전히 같지는 않다**. 다만 키보드·내비바는 OS 레이어라 재현성이 높다.
> Expo Go에서 **문제가 보이면 production에서도 거의 확실히 문제**다(역은 성립 안 함).

**기기마다 기록할 것**: 제조사·모델 / Android 버전 / 화면 크기 / 내비게이션 방식(3버튼 or 제스처).
→ 제스처 내비게이션과 3버튼은 하단 inset이 달라서 **FAB·탭바·입력창 겹침 결과가 다르다.**

---

## 1. 🔴 최우선 — 키보드 겹침 (앱에 3가지 방식이 혼재)

이 앱은 화면마다 키보드 대응이 다르다. **같은 결과를 기대하면 안 된다.**

### A. JS 수동 리프트 (`暫定` 마커 붙은 2곳)
`keyboardDidShow`의 `endCoordinates.screenY`로 가림량을 계산해 화면 전체를 올린다.
**"OS가 리사이즈/팬을 안 한다"는 가정에 의존** — 코드 주석에 *"전 기기 보장 원리적으로 불가"* 라고 적혀 있다.

- [ ] `자유게시판 글 → 댓글 입력` — 입력창이 키보드 위로 올라오는가
- [ ] `유학생 라운지 글 → 댓글 입력` — 동일
- [ ] 「返信」 탭 → **키보드가 뜨는가** (과거 안드로이드에서 안 뜨던 버그. `replyFocusNonce`로 수정됨)
- [ ] 키보드 열린 상태에서 **다른 댓글의 「返信」 탭** → 바로 먹히는가 (`keyboardShouldPersistTaps`)
- [ ] 멘션칩 「@匿名N ✕」 상태에서 Backspace → 멘션만 지워지는가

> **깨지는 양상 2가지**: ① 입력창이 키보드에 **가려짐**(리프트 0) ② 화면이 **이중으로 밀림**(OS도 리사이즈하는 기기)

### B. `KeyboardAvoidingView` (4곳)
과거 실측에서 **안드로이드는 무동작**이었다는 기록이 있다. 지금도 그런지 확인.

- [ ] 게시판 글쓰기 (`boards/create`) — 본문 입력 시 가려지는가
- [ ] 게시글 작성 (`post/[boardId]/write`)
- [ ] 라운지 글 작성 (`lounge/[loungeId]/write`)
- [ ] 쪽지 대화 (`messages/[chatId]`) — 입력창이 키보드 위에 있는가

### C. 아무 대응 없음 (8곳) — **가장 위험**
입력창이 화면 하단에 있으면 키보드에 가려져도 올려주는 코드가 없다.

- [ ] **계정 가입** (`account`) — 입력 4칸(닉네임·메일·비번·비번확인). **작은 화면에서 아래 2칸이 가려지는지**
- [ ] **로그인** — 비번 칸이 가려지는가
- [ ] **문의하기** (`contact`) — 본문·회신처
- [ ] **프로필 학업정보 편집** (`profile`)
- [ ] 강의검색 / 게시판 검색 / 시간표 메이커 — 검색창은 상단이라 보통 안전하나 확인

## 2. 🔴 하단 겹침 (내비게이션 방식별로 다름)

- [ ] **탭바 5개 라벨**이 잘리지 않는가 (`プロフィール`가 가장 긺)
- [ ] 탭바가 시스템 내비바와 **겹치지 않는가** (제스처/3버튼 각각)
- [ ] 라운지 **＋ FAB**가 내비바에 가리지 않는가 (`insets.bottom + 24` 적용됨)
- [ ] 게시판 FAB
- [ ] 새 메시지/새 댓글 **빨간 점**이 아이콘 우상단에 보이는가

## 3. 🟡 아이콘·폰트 (실기기에서만 드러남)

- [ ] 탭바 SVG 아이콘 5종이 **깨지지 않고** 렌더되는가 (이모지→SVG로 교체한 이유가 두부(□) 회피)
- [ ] 이모지 사용처(`🎓 卒業要件`, `🌏 留学生ラウンジ`, `📌`, `🚩`, `🚫`)가 두부로 안 뜨는가
- [ ] 앱 아이콘·스플래시 (교체 후 재확인)

## 4. 🟡 계정 삭제 (Apple 5.1.1(v) / Play 동등 요건)

준희가 10/23에 iOS 실기기에서 멈춤 버그를 고쳤다(`withTimeout` + 정적 import). **안드로이드에서도 되는지는 미확인.**

- [ ] 가입 → 프로필 → 계정 관리 → 계정 삭제 → 비번 재인증 → 삭제 완료 **알림이 뜨는가**
- [ ] 삭제 후 **같은 메일로 재가입 가능한가** (= Auth 계정이 실제로 지워짐)
- [ ] 삭제 직후 프로필 화면에 **권한 에러 빨간 화면이 안 뜨는가**
- [ ] 실패 시 **다시 시도 버튼**이 눌리는가

## 5. 🟢 기본 흐름 1사이클 (기기당 1회)

- [ ] 온보딩(약관→언어→학교) → 게스트로 진입
- [ ] 강의검색 → 시간표 추가 → 홈에 표시
- [ ] 졸업요건 → 학부·학년 선택 → 나갔다 복귀 시 **선택 유지**
- [ ] 게시판 글 작성 → 댓글 → 조회수 증가
- [ ] 친구 추가(이메일) → 쪽지
- [ ] 신고·차단 → 차단 해제
- [ ] 테마 변경(다크 포함) → 재시작 후 유지
- [ ] 한국어 전환 → 주요 화면 문구 확인

## 6. 보고 양식

문제를 찾으면 **증상 + 기기 정보 + 화면 캡처**를 같이 남긴다. 특히 키보드 건은
`Android 버전 / 내비게이션 방식 / 화면 높이`가 원인 추적에 꼭 필요하다.

```
기기: (제조사 모델 / Android N / 제스처 or 3버튼)
화면: (예: 자유게시판 댓글 입력)
증상: (예: 입력창이 키보드에 가려짐. 리프트 안 됨)
재현: 매번 / 가끔
```
