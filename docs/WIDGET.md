# 홈 화면 위젯 「今日の時間割」 (RELEASE-PLAN N4)

> **상태 (2026-11-17)**: ✅ **아이폰 실기기 확인 완료**(시험판 빌드 8·9 + 시험판 OTA, 준희) — 작은=오늘 목록 · 중간·큰=이번 주 표 · 다크 모드 · **◀ ▶ 로 친구 페이지 넘기기**까지 동작. 1.1.0 에 넣는다.
> 안드로이드는 이번엔 안 한다(SDK 57 공식 지원 없음 — §6).
> 근거 문서: Expo 공식 문서 v57 `sdk/widgets`(GitHub 원문 `expo/expo` `docs/pages/versions/v57.0.0/sdk/widgets.mdx` — docs.expo.dev 는 작업 환경에서 막혀 원문으로 읽음) + 패키지 소스.

## 1. 무엇이 보이나 (11/17 준희 결정으로 바뀜)

| 크기 | 내용 |
|---|---|
| **작은(2×2)** | 날짜 + **오늘 시간표 목록**(時限·과목, 최대 5개). 지금 수업 빨강·다음 수업 파랑·끝난 수업은 흐리게. 넘치면 끝난 것부터 빼고 「ほか○コマ」 |
| **중간(4×2)** | **이번 주 시간표 표**(월~금, 토요일 수업이 있으면 토까지 × 쓰는 時限만). 오늘 열 진하게, 지금/다음 수업 칸은 과목 색으로 채움 |
| **큰(4×4)** | 중간과 같은 표, 칸이 커서 과목명이 3줄까지 |
| **잠금화면(직사각형)** | 「授業中/次の授業 · 2限 10:50–12:30」 / 과목명 / 교실 (오늘 것만) |
| **◀ ▶ (중간·큰)** | 「自分の時間割 → **よく使う友達**(친구 탭 「よく使う友達の編集」, 최대 6명)의 時間割」을 넘긴다. 오른쪽 위에 「1/3」. 친구가 없으면 버튼 대신 날짜. **iOS 17 이상**(16 은 버튼이 눌리지 않는다) |

- 준희 결정(11/17): 「다음날 수업보다는 전체 시간표, 위젯 크기에 맞게」 · 「옆으로 넘기면 친구 시간표」(→ 스와이프는 iOS 위젯에서 불가 → **◀ ▶ 버튼**) · 작은 위젯 = 오늘 목록 · **게시판은 넣지 않는다**(위젯이 스스로 새 글을 못 받아와 앱을 연 때의 글만 보이므로)
- ◀ ▶ 로 넘긴 페이지는 **다음 전환 시각**(수업 시작·끝, 0시)에 「自分」으로 돌아간다(위젯은 그 시각의 항목만 바꾸기 때문 — expo-widgets 의 버튼 동작)
- 친구 시간표는 **친구에게 공개된 것만** 표로 보인다. **이번 학기 시간표가 없는 친구·비공개 친구도 페이지는 만들고** 「まだ今学期の時間割がありません」/「時間割は非公開です」를 띄운다(11/17 — 준희가 친구 2명을 넣었는데 둘 다 시간표가 비어 ◀ ▶ 가 안 나왔다). 통신 오류인 친구만 그때는 뺀다. 앱이 홈을 열 때 읽고(한 사람당 30분에 1번까지), 위젯용으로 이 기기 안(App Group)에만 둔다 — 서버로 새로 보내는 것 없음
- 수업 없는 날 「今日は授業がありません」, 다 끝나면 「今日の授業は終わりました」, 시간표가 없으면 「時間割を登録すると…」, 7일이 지나면 「アプリを開くと更新されます」
- 탭하면 앱 홈. 다크 모드 대응. 앱 언어(일·한)를 따른다. 위젯 갤러리의 이름·설명은 일본어 고정 — 설명문(`app.json`)은 11/18 에 새 구성에 맞게 「今日の授業・今週の時間割・よく使う友達の時間割を…」로 고쳤다(네이티브 문자열, 11/22 release 빌드부터)
- 보여 주는 건 **지금 학기**의 시간표(홈에서 다른 학기를 보고 있어도). 교시 시간은 앱 공통 `PERIOD_TIMES`
- 홈의 「その他」 칸(요일·교시 없는 수업, I-8 2026-11-20)은 **위젯에 넣지 않는다** — `widgetService` 가 `placedSessions()` 로 표에 놓이는 수업만 넘긴다(day/period 가 null 이라 §4 의 null 금지에도 걸린다). 친구 시간표도 같다
- 🔑 **위젯 화면(레이아웃)과 표시 내용은 앱 JS 쪽이라 OTA 로 바꿀 수 있다** — 앱이 켜질 때 `createWidget` 이 레이아웃 문자열을 App Group 에 새로 써 넣고, 위젯은 그걸 읽어 그린다. **새 빌드가 필요한 건** 크기 종류(`supportedFamilies`)·갤러리 이름/설명·위젯 종류 추가뿐(`app.json`) — 11/21 네이티브 동결 이후엔 못 바꾼다

## 2. 어떻게 움직이나

```
홈 화면이 지금 학기 시간표를 읽음/저장함
  → widgetService.updateTodayWidget()  (아이폰 + 새 앱에서만)
  → 앞으로 7일치 「언제부터 무엇을 보일지」 목록(타임라인)을 만들어 위젯에 넘김
       = 오늘·내일은 0시 + 각 수업 시작·끝 / 3일째부터는 0시만 (친구 2명 ≈ 22KB, 6명 꽉 차도 ≈ 66KB)
  → 아이폰이 그 시각마다 위젯을 바꿔 그림 (앱이 꺼져 있어도)
  → 7일이 지나거나 학기가 바뀌는 날엔 「アプリを開くと更新されます」
```
- 같은 내용·같은 시간대면 다시 쓰지 않는다(위젯 새로고침 낭비 방지)
- 로그아웃·계정 삭제 → 홈이 새(게스트) 시간표를 읽으면서 위젯도 비워진다

## 3. 파일

| 파일 | 역할 |

| `src/widgets/TodayTimetableWidget.tsx` | 위젯 화면. `'widget'` 표시 함수 = **앱과 따로 도는 작은 JS 환경**에서 실행 |

## 4. 지켜야 할 것 (어기면 위젯이 빈 화면이 되거나 옛 앱이 멈춘다)
- 🔴 **위젯 파일을 직접 import 하지 않는다** — 반드시 `widgetService` 경유. `expo-widgets` 는 읽는 순간 네이티브 부품을 찾아서, 부품 없는 **스토어 1.0.0(OTA 로 같은 JS 가 감)**·안드로이드·웹에서 읽으면 멈춘다(AGENTS.md 「새 네이티브 모듈」 규칙)
- 위젯 함수 안에서는 **`@expo/ui/swift-ui` 부품·수식어만**. 훅·import·비동기·**함수 밖 상수** 금지 → 값은 props 로, 도우미는 함수 안에
- Babel 보조 함수가 붙는 문법(객체 `...`펼침·구조 분해·for-of·class) 금지 — 위젯 쪽엔 보조 함수가 없다. import 한 이름을 바꾸지 않는다(`Text as T` ✕)
- 🔴 **위젯에 넘기는 데이터에 `null`(·`undefined`·NaN) 금지** — 아이폰은 위젯 데이터를 UserDefaults(App Group)에 저장하는데, 여기엔 null 을 못 넣는다. 넣으면 **네이티브 예외로 앱이 강제 종료**(JS try/catch 로 못 막음) → 켜자마자 꺼지니 **OTA 가 자동으로 이전 버전으로 되돌아간다**(겉으로는 「업데이트가 안 뜬다」). 11/17 시험판에서 실제로 났다(주간표 빈 칸을 null 로 넘김). 지금은 ① 빈 칸 = `0` ② 넘기기 직전 `plistSafe()` 로 한 번 더 걸러낸다. Node 시뮬레이션은 이 저장 규칙을 흉내 내지 않으므로 **값 검사를 따로** 한다
- 쓸 수 있는 부품: Text·VStack·HStack·ZStack·Spacer·Divider·Rectangle/RoundedRectangle/Capsule/Circle·Image·Label·ProgressView·Gauge·Button·Link (`expo-widgets/ios/Widgets/DynamicView.swift` 목록)

## 5. 검증 (11/14)
- `npx tsc --noEmit` 통과
- `expo prebuild`(임시 복사본): 위젯 확장 타깃 `jp.timetable.app.ExpoWidgetsTarget`, App Group `group.jp.timetable.app` 이 **본체·위젯 양쪽** entitlements 에, 위젯 버전 = 본체 버전(1.1.0)·빌드 번호는 EAS 원격 번호를 따른다
- iOS 번들 분석: 위젯 레이아웃 문자열에 보조 함수 참조 없음(`_jsx`·`_jsxs` 만 — 위젯 환경이 제공) · 네이티브 부품을 찾는 모듈은 **위젯 모듈 → `widgetService` 함수 안 지연 require** 로만 닿음
- **실제 위젯 실행 환경 번들**(`ExpoWidgets.bundle`, 설치된 버전으로 빌드)에 앱 번들의 레이아웃을 넣고 렌더: 4크기 × 6상황 렌더 OK, 모르는 부품 없음 + 타임라인 계산 12건(수업 중→次→끝, 토·일, 7일 뒤, 학기 경계, 한국어) — 전부 통과
- 안드로이드·웹 번들 생성 정상
- 🔸 버전 고정 이유: 최신 `expo-widgets` 57.0.28 은 `@expo/ui` 57.0.26 을 따로 끌고 와 **같은 부품 2벌**이 됐고, 57.0.23 부터 위젯 전용 수식어(widgetURL 등)가 `@expo/ui` 에서 `expo-widgets` 로 옮겨져 **섞어 쓰면 깨진다**. 지금 SDK(expo 57.0.23)가 짝으로 지정한 57.0.19 + 57.0.18 로 맞췄다. SDK 를 올릴 때 둘을 **같이** 올린다
