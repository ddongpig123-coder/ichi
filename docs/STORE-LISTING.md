## 전체 설명 (JA 정본)

```
ichi は、日本の大学生・留学生のためのコミュニティアプリです。
時間割づくりから友達づくり、講義選びまで、大学生活をまるごとサポートします。

■ 時間割 × 友達
・講義を検索してワンタップで時間割に追加
・友達と時間割を共有し、「一緒に受けている講義」を自動でハイライト
・公開範囲は「非公開／友達まで」から選べます

■ 講義を選ぶ
・2万件を超える講義データから検索（講義名・教授名）
・星評価とタグ（単位の取りやすさ・出席確認・留学生フレンドリー等）で講義レビューを確認
・シラバス情報と評価をまとめて講義詳細でチェック

■ つながる・相談する
・学校ごとの匿名掲示板（自由／質問／サークル／教科書ゆずり など）
・全国の留学生ラウンジ（ビザ／アルバイト／住まい／売買／就活）
・メッセージで友達とやりとり

■ 安心して使える
・登録なしのゲストですぐに利用開始。あとからメール等でデータを引き継げます
・大学メール認証で「認証バッジ」を付与
・通報・ブロック機能。運営は通報を原則24時間以内に確認します

まずはゲストで、あなたの大学生活をもっと便利に。
```

## 전체 설명 (KO 참고 번역)

```
ichi는 일본의 대학생·유학생을 위한 커뮤니티 앱입니다.
시간표 만들기부터 친구 사귀기, 강의 선택까지 대학 생활을 통째로 지원합니다.

■ 시간표 × 친구
· 강의를 검색해 원탭으로 시간표에 추가
· 친구와 시간표를 공유하고 "함께 듣는 강의"를 자동 하이라이트
· 공개 범위는 "비공개 / 친구까지" 중 선택

■ 강의 선택
· 2만 건 이상의 강의 데이터에서 검색(강의명·교수명)
· 별점과 태그(학점 난이도·출석 확인·유학생 친화 등)로 강의 리뷰 확인
· 시라버스 정보와 평점을 강의 상세에서 한눈에

■ 연결·상담
· 학교별 익명 게시판(자유/질문/동아리/교과서 물려받기 등)
· 전국 유학생 라운지(비자/아르바이트/주거/거래/취업)
· 메시지로 친구와 소통

■ 안심 사용
· 등록 없이 게스트로 바로 시작. 이후 이메일 등으로 데이터 인계 가능
· 대학 메일 인증으로 "인증 배지" 부여
· 신고·차단 기능. 운영은 신고를 원칙 24시간 이내 확인

먼저 게스트로, 당신의 대학 생활을 더 편리하게.
```
