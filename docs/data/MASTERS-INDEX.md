# 졸업요건 마스터 인덱스 (학교 × 학부 × 연도)

> 파일명 규칙: `<school>-<faculty>-<year>.json` (메이지는 역사적으로 `meiji-` 접두사 생략 없이 동일 규칙).
> **메이지 외 학교는 JSON만 축적** — 앱(`src/data/facultyMasters.ts`)은 아직 meiji.ac.jp 전용이라
> 다학교 통합은 별도 작업(출시 블로커 아님).
> ⚠️ **학교마다 표의 셈법이 다르다.** 메이지는 「영역 최저단위 합 = 졸업단위」가 성립하지만,
> 早稲田 商처럼 **중복 산입(한 과목이 두 영역에 동시 산입)** 과 **영역 최저 합 < 졸업단위** 인 곳이 있다.
> 그런 마스터는 `_validation` 블록에 산식을 적어 재검증 가능하게 둘 것.

> 便覧은 **입학년도별로 존재**하고 요건이 바뀔 수 있어, 마스터는 **(학부 × 입학년도)** 단위로 보관한다.
> 앱은 사용자 **입학년도**로 해당 마스터를 고른다. 便覧 수령 시 이 표에 반드시 **연도**를 기록할 것.

## 他校 수집 메모 (2026-10-11 착수)
- **早稲田 商学部 완료**. 공개 학부요항 PDF: `https://www.waseda.jp/fcom/soc/students/guide` (연도별 전부 공개).
  - ⚠️ **Cloudflare**: PowerShell `Invoke-WebRequest`는 챌린지에 막힘. **curl + 브라우저 User-Agent + Referer** 로 통과됨.
  - ⚠️ **표 셈법이 메이지와 다름**: 外国語専門科目分野 4단위가 「外国語科目選択8」과「専門教育科目52」에 **이중 산입**.
    영역합 112 − 중복 4 = **108**(요항의 중괄호 "108単位以上") + 他箇所 상한 16 = **124** ✓.
    하위영역은 **바닥값**이고 그룹 최저가 따로임(専門教育 하위합 32 < 그룹 52). `subZonesAreFloors: true`로 표기.
  - 正誤表(2026-07)는 더블디그리 64단위 표만 수정 — 정규입학자 요건엔 영향 없음(받은 PDF는 이미 반영본).
- **파이썬 없는 PC에서의 PDF 처리 레시피** (이 레포 `scripts/parse_*.py`는 pymupdf라 로컬 실행 불가):
  - 텍스트: `pdfjs-dist@4` + y좌표 행 그룹핑 (대부분 이걸로 충분)
  - 이미지 렌더(목시용): `pdfjs-dist@3.11.174` + `@napi-rs/canvas`, scale 2.6
    (**pdfjs 4 + napi-rs canvas 조합은 `ctx.fill(Path2D)`에서 깨짐** — v3을 쓸 것)
  - 결합셀/중괄호 범위는 텍스트로 판별 불가 → **반드시 렌더해서 눈으로 확인**
