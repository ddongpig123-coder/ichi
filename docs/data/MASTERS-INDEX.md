## 수령 대기 / 다음
- 다른 학부 便覧(연도 명기) 수령 → 같은 스키마로 영역 마스터 추가
- 각 학부 **배당표(授業科目配当表: 과목→科目群)** → CAN·과목 자동분류용 (영역만 상태를 완성으로 승격)
- 앱 통합(C 마지막 단계): 다학부 구조 리팩터링 + 학부/연도 선택 + "준비중" 해제

## 便覧 연도 주의
- 같은 학부도 **입학년도에 따라 요건·과목이 다를 수 있음**. 파일명·_meta.admissionYear·appliesTo에 연도를 반드시 명시.
- 사용자가 준 PDF가 "2026년도 이후"인지 "특정년도 이전"인지 표지/페이지에서 확인 후 기록.
