## ✅ 文学部 배당표 완성 (2026-10-14) — 지금까지 중 가장 복잡
`meiji-literature-allocation-2026.json` (914과목) + `src/data/allocationLiterature.ts` + 앱 CAN(학과별).
便覧 「Ⅳ 科目配当表及び履修上の留意点」(p40~). **표 형식이 한 학부 안에서 4종류**로 갈린다:
- **A** 전 전공 공통 外国語/ウェルネス (対象学科 열 있음)
- **B** 전공별 ⑴専攻必修科目 (必要単位数가 병합셀)
- **C** 전공별 ⑷専攻選択科目Ａ (**2단 조판** + 設置専攻 열)
- **D** ⑵共通選択科目 (**열 순서가 다름**: ジャンル|科目名|配当年次|単位|総授業時間数)

**검증: 14개 전공 전부 「必要単位数」합계가 마스터와 일치** — 文学科 6전공=38 / 史学地理 5전공=32 /
心理社会 3전공=30. 전 학과·전 영역에서 풀 ≥ 최저단위 통과. 스킵 0행.

**함정 2개 (다른 便覧에도 재발 가능)**
1. 🔴 **必要単位数(병합셀) 값이 과목 행이 아니라 독립 행에 뜬다.** 과목 행에서만 주우면 취락이 나서
   처음에 14전공 중 6전공이 불일치했다(日本文学 24/38 등). **req 열의 숫자를 행과 무관하게 수집**해야 함.
   → 法 때의 "그룹 전환 전 선수집" 함정과 **반대 방향의 같은 뿌리**(병합셀 처리).
2. 🔴 **페이지 좌우의 세로쓰기 사이드 견출(x≈591)이 표 헤더 행과 같은 y로 병합**된다.
   `ツ⑴専攻必修科目`가 돼서 헤더 정규식이 깨지고 독문·불문 専攻必修가 통째로 누락됐다. **x<580으로 제외**.

**미취득**: 史学地理学科의 日本史学·アジア史·西洋史学·地理学 4전공은 ⑷専攻選択科目Ａ 표가 본문에서
안 보여 미수집(考古学만 취득). 選択科目 풀은 共通選択181과목으로 최저단위를 넘기므로 진단엔 영향 없음.
