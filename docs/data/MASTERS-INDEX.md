## 便覧 연도 주의
- 같은 학부도 **입학년도에 따라 요건·과목이 다를 수 있음**. 파일명·_meta.admissionYear·appliesTo에 연도를 반드시 명시.
- 사용자가 준 PDF가 "2026년도 이후"인지 "특정년도 이전"인지 표지/페이지에서 확인 후 기록.
