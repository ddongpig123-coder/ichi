## 4-1. 출시(1.1.0) 직전에 잊지 말 것 — N1 관련

1. `npm run deploy:functions` 한 번 더 (11/14 이후 서버 수정분: 빈 결과는 횟수 안 씀 · 계정 삭제 시 이용 기록 삭제 · **푸시 알림 함수 5개**)
1-1. **안드로이드 FCM 설정**(google-services.json 을 EAS 환경변수로 · FCM V1 키) — 안 하면 안드로이드에선 알림이 안 온다. [PUSH-NOTIFICATIONS §5-3](PUSH-NOTIFICATIONS.md)
2. `npm run deploy:web` — 웹 CSP(함수 주소)·개인정보처리방침이 나간다
3. **gh-pages 의 `privacy.html` 을 `docs/legal/privacy.html` 로 교체**(스토어에 등록된 방침 URL — [docs/legal/README.md](legal/README.md))
4. App Store 「앱 개인정보」·Play 「데이터 보안」에 **사진** 추가 — 용도 「앱 기능」, 신원과 연결 안 함, 추적 안 함 / Play 는 「일시적으로만 처리」·서비스 제공자 전송(공유 아님). 푸시 토큰도 「기기 또는 기타 ID」에 해당하는지 제출 때 확인
5. 심사 노트: 「시간표 스크린샷 읽기는 Anthropic API 로 보낸다. 보내기 전 화면에서 동의를 받는다」 + 시험용 스크린샷 1장
6. 🔴 **EU 디지털서비스법(DSA) 「트레이더 여부」 신고** — EU 에 안 팔아도 필수(11/14 App Store Connect 알림). 안 하면 업데이트 제출이 막힌다.
   추천: 앱의 「가격 및 사용 가능 여부」에서 **EU 27개국 해제**(일본·한국은 유지) → 비즈니스 → 계약 → 규정 준수 → Digital Services Act → **「This is not a trader account」**.
   트레이더로 신고하면 주소·전화·이메일이 EU 앱스토어에 공개된다. 근거: Apple 「Manage EU DSA trader requirements」 — EU 앱스토어에 배포하지 않으면 앱스토어상 트레이더로 활동하는 게 아님(법률 자문 아님)
   - ✅ 11/14 개발자 프로그램 라이선스 약관 갱신 동의 완료(준희)

## 4-2. 🔴 출시일 순서 — 버전·OTA (틀리면 기존 사용자에게 OTA 가 끊긴다)

| 언제 | 할 일 | 왜 |
|---|---|---|
| 심사 제출 빌드 | `eas build --profile release --platform ios`(·android) — **`app.json` 은 1.0.0 그대로**, 이 빌드만 1.1.0(`APP_VERSION_OVERRIDE`)·채널 production | 심사 기간(12/12~19)에도 1.0.0 사용자에게 OTA 로 고칠 수 있게 |
| 심사 기간 | `npm run ota -- "…"` = 1.0.0 사용자에게 / `npm run ota -- --beta "…"` = 시험판에 | runtime 이 다르면 서로 안 섞인다 |
| **스토어에 1.1.0 공개된 날** ① | `src/config/storeVersion.ts` 의 `STORE_LATEST` 를 공개된 플랫폼만 `"1.1.0"` 으로 → 머지 → `npm run ota -- "1.0.x: 새 버전 안내"` | 1.0.0 사용자에게 **마지막 OTA** = 「新しいバージョンがあります」(하루 1번, `UpdatePrompt`) |
| 〃 ② | 그 뒤 `app.json` version → `"1.1.0"`, `eas.json` 의 `release`·`beta` 덮어쓰기 정리 | 이후 `npm run ota` 는 1.1.0 사용자에게 간다 |

- 🔴 `STORE_LATEST` 에 **아직 스토어에 없는 버전**을 쓰면, 누르면 아무것도 못 받는 안내가 뜬다. iOS·Android 따로
- 안드로이드가 1.0.0 으로 먼저 정식 공개되는 경우(11/14 진행 중)도 같은 방식 — 안드로이드 1.1.0 공개 날 `android` 만 바꾼다
- `UpdatePrompt` 화면 확인(11/14, 임시 빌드): 표시·「あとで」 뒤 같은 날 다시 안 나옴·콘솔 오류 0

## 5. 위험과 대책

1. **심사 거절** — 사진 권한 문구 · AI 전송 동의 · 알림 권한 · 개인정보 표시를 미리 맞춘다. 12/12 제출이면 2번까지 재제출 여유
2. **위젯이 가장 큰 일정 위험** → 12/3 에 판단해서, 안 되면 다음 업데이트로
3. **새 버전이 나오면 옛 버전(1.0.0) 사용자에게는 그 뒤 OTA 가 안 간다**(새 부품이 없는 앱에 새 코드를 보내면 멈추므로 런타임을 나눈다).
   → 출시 직전 마지막 OTA 에 **「新しいバージョンがあります」 업데이트 안내**를 넣어, 옛 버전 사용자를 스토어로 보낸다
   → ✅ 11/14 구현(`src/config/storeVersion.ts`·`UpdatePrompt`). 켜는 순서는 §4-2
4. **출국 후 운영** — ✅ **맥북 지참 확정(11/14 준희)**. 캐나다에서도 OTA·규칙 배포·심사 대응·다음 업데이트 작업을 이어 간다(시차만 주의)
