## 7. 기획·운영 양식 (11/13 준희가 공유한 SNS 프롬프트 7종 중 채택분)

> 원본은 「계정 정보를 모르는」 범용 프롬프트다. 우리는 계정 정보(타깃·톤·금지선·예시 6개)가 문서에 다 있으니, **양식만 가져와 우리 정보로 채운다.**

### 7-1. 후킹 문구 (원본 2번) — 릴스·캐러셀 1장째에 공통
- 소재 하나당 **후킹 30개**를 5종류로: **호기심 / 반전 / 결과 제시 / 스토리 / 질문** (각 6개)
- 길이: 일본어 **15자 안팎** (원본의 「12단어 미만」을 일본어로 환산)
- 그중 **「무음으로 봐도 멈추게 하는」 문구 10개를 순위로** — 릴스는 대부분 소리 없이 본다 → 화면 글자만으로 통해야 한다
- 그중 **캐러셀(카드) 1장째에 더 맞는 3개**를 따로 고른다 (결말 숨기기형 — MARKETING §3-3 예시 ⑥)

### 7-2. 릴스 대본 (원본 4번) — 대본 1개 = 아래 6칸
| 칸 | 내용 |
|---|---|
| ① 첫 문장 | 0~1초에 화면에 뜨는 말 (§7-1 순위 1~5위에서) |
| ② 구간별 화면 | 0–3초 / 3–10초 / 10–20초 / 20–30초 각각 무엇을 보여주나 (실사 배경·UGC 컷·앱 녹화) |
| ③ 화면 글자 | 구간마다 자막 1줄 (무음 전제) |
| ④ 템포 | 컷 길이(초), BGM 박자, 빨라지는 지점 |
| ⑤ 🔴 이탈 순간 | 시청자가 **계속 볼지 정하는 정확한 초**(보통 1.5초·3초)와 **그 순간 붙잡는 장치**(반전 자막·화면 전환·숫자 공개 예고) |
| ⑥ 마무리 | 팔로우 유도 한 줄 + 앱 언급(프로필 링크) |
- 길이 30초 미만. 기획 단계에서 **5개** 쓰고 그중 3개를 만든다

### 7-3. 캐러셀 — 정보 카드일 때만 (원본 3번)
- 표지 → 핵심 약속 1장 → **본문 6장(장마다 아이디어 1개)** → 행동 유도 1장 = 9장
- 장마다 제목·본문·디자인 방향 / 캡션 + **첫 댓글(추가 팁)**까지
- 뉴스형(2~3장 결말 숨기기)·究極の2択에는 쓰지 않는다

### 7-4. 일정이 꼬이면 줄이는 순서 (원본 6번)
1. 먼저 줄인다: **정보 카드(§7-3)** — 제작 시간이 가장 길다
2. 그다음: 뉴스형 카드 개수 (주 3 → 1)
3. 끝까지 지킨다: **수요일 究極の2択** (고정 코너가 끊기면 팔로워가 잊는다) · 릴스 주 1개(시작한 뒤)
- 매주 **즉흥 게시 2칸**은 비워 둔다 (그 주 화제에 바로 반응)

### 7-5. 매주 일요일 지표 2개 + 매달 실험 1개 (원본 7번)
- **주간 지표 2개** (초반 기준)
  1. **저장 수** — 인스타가 가장 크게 보는 신호(MARKETING §9-2). 「다시 볼 가치」의 증거
  2. **프로필 방문 수** — 앱 설치로 이어지는 유일한 입구
  - 기록: [MARKETING-2026-11 §7-9 게시 기록표](MARKETING-2026-11.md). 팔로워 수는 참고만(초반엔 흔들림이 커서 판단 근거로 약하다)
- **비교 기준**: 지난 4주 평균 대비. 첫 4주는 첫 게시를 기준점으로
- **매달 답할 질문 3개**: ① 저장이 가장 많은 형식은? ② 프로필 방문으로 이어진 소재는? ③ 계속할 가치가 없는 코너는?
- **코너를 접는 기준**: 3주 연속 저장·프로필 방문 둘 다 계정 평균의 절반 미만이면 접는다(이름만 바꿔 재도전 1회 허용)
- **매달 실험 1개** 칸 (예: 11월 = 뉴스형 결말 숨기기 / 12월 = 첫 릴스) — 월말에 결과 한 줄

### 예시 R1 — 「裸眼チェッカー」 렌즈 소개 (약 31초, 한국어 크리에이터)
| 구간 | 화면 | 화면 글자 |
|---|---|---|
| 0–2초 🔴후킹 | 눈 클로즈업 + 🇯🇵 + 렌즈 | 「내 눈동자 크기를 알 수 있는 렌즈?!」「일본 가면 꼭 사야 함」 |
| 3–4초 | 제품 상자 손에 들고 | 「평소에 컬러렌즈 직경 몇 mm 될지 매번 고민이었는데」(공감 문제 제기) |
| 5–6초 | 손끝 렌즈 + **집중선 효과** | 「신기한 신박템 찾음」 |
| 7–12초 | 상자→렌즈 착용 | 「이게 일본에서 나온 맨눈 체커라는 렌즈인데」「눈동자 직경이 몇 mm인지 확인」「컬러까지 비교」 |
| 13–20초 | 손 데모 컷 1초씩 | 「더 대박인 건」→「도수까지 선택」→**「가격도 2개입에 단돈 500엔?」** |
| 21–26초 | 판매처 + **남의 댓글 화면**(「진짜 신박템」) | 「〇〇 매장에서 구매」「자세한 위치는 캡션에」 |
| 27–31초 | 다시 첫 장면 | 「일본 가시는 분들은 한번 써 보시는 거 추천!!」→ **첫 화면으로 루프** |

### 예시 R2 — 「渋谷109 カラコン専門店」 길 안내 (약 38초)
| 구간 | 화면 | 화면 글자 |
|---|---|---|
| 0–6초 🔴후킹 | 매장 진열대 B롤 | **3단 제목**: 「렌즈 종류만 무려 900개?」/ **「시부야109 호테라바」(노란 굵은 글씨)** /「일본에서 렌즈 사려면 여기로 가세요」(노란 형광) |
| 7–12초 | 109 건물 외관 → 간판 | 「시부야109에 컬러렌즈 전문점이 있는 거 아시나요?」 + **아래에 일본어 자막** 「渋谷109にカラコン専門店があるの知ってる?」 |
| 13–16초 | 에스컬레이터 → B1F 표지 → 매장 입구 (**POV 길 안내**) | 「지하 1층에 있는」「일본 대형 컬러렌즈 전문점!」 |
| 17–28초 | 진열대 → 직경 라벨 클로즈업 → 랭킹 1·2·3위 | 「직경별·컬러별로 나뉘어 있어서」「신작/월간 랭킹까지 한눈에」 |
| 29–33초 | 무료 시착 안내판 → 시착대 | 「궁금한 렌즈는 직접 착용해 볼 수 있대」「최대 4종까지」 |
| 34–38초 | 가격표 클로즈업 | 「원데이/먼슬리로 나뉘어 있고」**「2480엔」** |

### 두 예시의 공통 규칙 → 우리 릴스에 그대로
1. **첫 1~2초 = 숫자 들어간 질문 + 명령형** — 「무려 900개?」「단돈 500엔?」 + 「꼭 사야 함」「여기로 가세요」. 이탈 순간(1.5초)을 숫자로 붙잡는다
2. **컷 = 거의 1초에 하나**, 컷마다 자막 한 줄. 무음으로 봐도 다 이해된다
3. **문제 → 발견 → 디테일 → 가격 → 어디서 → 추천** 순서. 저장할 이유(가격·장소)가 영상 안에 있다
4. **실제 촬영**이다(AI 영상 아님). 손 데모·POV 걷기·클로즈업. 집중선 같은 **편집 효과**로 템포를 낸다
5. **증거**: 남의 댓글 화면, 랭킹 1위 표시 → 「사람들이 이미 좋아한다」
6. **마무리 → 첫 화면 루프**: 끝까지 본 사람이 한 번 더 보게 된다(재생 시간↑)
7. **「자세한 건 캡션에」** → 캡션까지 읽게 만든다
8. R2의 **2개 국어 자막**(한국어 위 + 일본어 아래) → 우리는 **일본어 위 + 한국어 아래**로 쓰면 일본 대학생과 한국인 유학생을 한 영상으로 동시에 잡는다 (📌 우리 차별점과 딱 맞음)

- 예시 둘 다 **준희가 폰으로 찍을 수 있는 실사 영상**이다 → **단계 3(촬영)이 핵심**이 되고, Higgsfield는 **보조**(전환 컷·B롤·없는 장면 보충)로 내려간다
