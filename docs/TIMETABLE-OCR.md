# 시간표 스크린샷 → AI 자동 입력 (검토 기록 · 2026-11-05)

> 준희 제안: 학교 포털 시간표 스크린샷을 올리면 AI가 읽어서 앱 시간표를 채워주는 기능.
> **결론: 지금은 정확도 테스트만 하고, 구현은 1.2(재빌드 묶음, 1월 빌드)에서.** 이유와 결정값은 아래.

## 1. 왜 이번 OTA에 못 넣나 (코드에서 확인한 사실)
- 사진 선택에 필요한 네이티브 모듈(`expo-image-picker` 등)이 **설치돼 있지 않다**(package.json에 사진·카메라·파일 모듈 0개). 네이티브 모듈은 **OTA로 못 보내고 재빌드 + 재심사**가 필요하다.
- 서버가 없다. `functions/` 없음, `firebase.json`은 규칙·호스팅뿐, 요금제는 Spark(무료). API 키를 앱에 넣을 수 없으므로 서버(Cloud Functions = **Blaze 전환**)가 선행.
- 1.1은 12/08 동결까지 S4~S10으로 꽉 차 있고, 수요는 4월 履修登録에 몰린다 → ROADMAP의 **Phase 2.5 시간표 작성 도우미(2~3월)** 와 1.2 재빌드 묶음(위젯·푸시·초대링크·R8)에 넣는 것이 맞다.

- 정답 파일(`--truth`)을 주면 的中率이 나온다. 형식은 스크립트 머리말 참조.

### 3-1. ✅ 결과 (2026-11-14) → **Sonnet 5.5 로 결정**

사진 5장: Oh-o!Meiji **폰 스크린샷 2장**(春·秋) + **PC 화면 1장**(글자가 작고, 채팅 전달 과정에서 2000px 폭으로 줄어든 것) +
참고용으로 **한국 대학 앱 시간표 2장**(시각 기준 표 — 채점 제외). 정답은 명치 3장 **22과목**(요일·시한·과목명 앞 4글자 일치로 채점).
(이미지·결과 JSON 은 개인 시간표라 저장소에 두지 않는다. `scripts/output/` 은 gitignore)

| | Haiku 5.5 | **Sonnet 5.5** | Opus 5.5 |
|---|---|---|---|
| 的中 (명치 22과목) | 21/22 (95%) · 余分 1 | **22/22 (100%) · 余分 0** | 22/22 (100%) · 余分 0 |
| 폰 스크린샷 2장 | 19/19 | 19/19 | 19/19 |
| PC 화면 1장 | **2/3** — 과목명 1개 오독(「商学専門演習」→「国際学専門演習」), 교실·교원명도 오독 | 3/3 | 3/3 |
| 1장당 비용(실측) | $0.0011 | **$0.0140** | $0.0343 |
| 1장당 시간(명치) | 2.4~6.2초 | 3.2~4.1초 | 4.0~6.0초 |
| 요일·시한 없는 미디어〔M〕 3과목 | 전부 「枠外」로 분리 ✅ | ✅ | ✅ |

- **결정 이유**: 사전 기준(Haiku 95% 이상)에는 **경계선으로 걸린다**(21/22). 그래도 Sonnet 으로 간다 —
  ① 표본이 22과목뿐이라 95% 는 1개 차이, ② 틀린 1개가 **과목명 자체**(사용자가 직접 고쳐야 하고 첫인상이 깨짐),
  ③ 「1인·학기당 1회」 제한이라 **절대 금액이 작다**: 사용자 1,000명 × 연 2학기 = 2,000장 × $0.014 ≈ **$28/년**
- **Opus 는 쓰지 않는다**: Sonnet 대비 정확도 이득 0, 비용 2.5배, 더 느림
- 폰 스크린샷만 보면 Haiku 도 완벽했다. 비용이 문제가 되는 규모가 오면 「Haiku 먼저 → `confidence: low` 가 있으면 Sonnet 재시도」를 검토

### 3-2. 테스트에서 나온 1.2 설계 반영 사항
- 🔴 **교시 시간표가 프롬프트에 명치 기준(1限 09:00-10:40 …)으로 고정**돼 있다. 한국 대학 시간표(시각 기준)에서 모델들이
  시한을 서로 다르게 붙였다 → 앱에서는 **사용자 학교의 교시 시간표를 프롬프트에 넣는다**(학교 데이터에 時限表 필요. 早稲田 등은 시각이 다르다)
- **「枠外」(요일·시한 없음) → 시간표의 「その他」 칸(I-8)** 으로 넣는다 → **I-8 이 사진 입력보다 먼저** 필요
- 모델이 `confidence: low` 를 붙인 칸(저해상도·글자 뭉개짐)은 **미리보기에서 강조**해 확인을 유도. PC 화면은 Sonnet 도 전부 low 였다 → 미리보기 수정 단계는 필수
- 추가 표본(다른 대학 포털·친구 시간표 5~10장)은 크레딧 만료(11/27) 전에 돌려 두면 좋다(이번 테스트 총비용 ≈ $0.25)

### 3-3. 테스트 중 걸린 함정 (재실행할 때)
- `@anthropic-ai/sdk` 1.8 은 API 키를 `Authorization: Bearer` 로 보낸다. **「Invalid bearer token」 = 키가 아닌 값**(`sk-ant-` 로 시작하지 않음)이 들어갔다는 뜻.
  틀린·만료 키는 「invalid x-api-key」로 나온다
- 새로 만드는 키는 **`sk-ant-usr-`** 로 시작한다(옛 `sk-ant-api03-` 만 검사하면 정상 키를 거부한다)
- 키를 터미널·채팅에 붙여넣으면 기록에 남는다 → 위 명령처럼 클립보드에서 읽고, 노출됐으면 Console 에서 즉시 삭제
