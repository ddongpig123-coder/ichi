> 자연스럽게 검색해서 앱을 알게 하기")에 대한 설계.
> [CONTENT-OPS.md](CONTENT-OPS.md)가 **앱 안을 채우는 일**이라면, 이 문서는 **밖에서 사람을 데려오는 일**이다.

## 1. 준희 아이디어의 핵심은 맞다 — 다만 한 군데만 바꾸자

> "에타에서 화제가 된 글이라는 걸로 카드뉴스처럼 만들어서 최근 화제를 전해주는 채널에 올리면,
> 본 사람들이 어느 사이트 내용인지 궁금해져서 검색해서 우리 앱을 알게 될 것 같다"

**유입 경로 설계는 정확하다.** 「재밌는 글 → 어디서 나온 거지? → 검색 → 설치」는 실제로 작동하는 깔때기다.
다만 소재를 **「에타에서 화제가 된 글」로 하면 안 된다.** 이유 둘:

1. **전환이 안 된다 (이게 더 치명적)** — 궁금해서 우리 앱에 들어온 사람이 **그 글을 못 찾는다.**
   "속았네" 하고 나가고, 다시 안 온다. 유입은 되는데 잔존이 0이면 광고비만 태우는 것과 같다.
2. **남의 서비스 이름과 남의 유저 글이다** — 에브리타임은 한국의 다른 회사 서비스이고,
   그 글의 저작권은 그 글을 쓴 사람에게 있다. 상표·저작권 양쪽에서 걸린다.

### 🟢 제대로 된 형태: **우리 앱에서 화제가 된 글**을 카드뉴스로

바꾸면 전부 해결되고, 오히려 더 강해진다.
- 출처를 「大学の森」로 명시 → 본 사람이 **앱에서 그 글을 실제로 찾을 수 있다** → 잔존
- 앱 이름이 콘텐츠마다 노출 → 검색 유입
- 법적으로 완전히 깨끗하다

> 🔑 **그리고 이게 앞 세션에서 정한 AI 시딩과 맞물린다.**
> 시딩한 글이 **그대로 카드뉴스 소재**가 된다. 앱 안을 채우는 작업이 **동시에 밖으로 나가는 콘텐츠**가 되는 것이다.
> 콘텐츠를 두 번 만들 필요가 없다. 이게 이 전략의 진짜 이득이다.

### ✅ 약관 근거는 이미 있다 (확인 완료)
`app/terms.tsx` **第5条2항**:
> 利用者は運営者に対し、本サービスの**提供・改善・広報**に必要な範囲で、投稿コンテンツを無償で利用
> （複製、表示、翻訳を含む）する権利を許諾するものとします。

**「広報」가 이미 명시돼 있다.** 유저 글을 홍보물로 쓰는 라이선스 근거가 확보돼 있다.
더 명확히 하려면 「SNS 등 외부 매체에의 게재를 포함한다」 한 구절을 덧붙이면 되지만, 필수는 아니다.
다만 **운영 실무 규칙은 따로 둔다**(§5).

## 2. 채널 — 일본 대학생이 실제로 있는 곳

| 채널 | 타깃 | 형식 | 우선순위 |
|---|---|---|---|
| **X (트위터)** | 일본 대학생 전반. 신입생 필수 | 카드뉴스 이미지 + 짧은 글 | 🟢 **1순위** |
| **Instagram (Reels + 피드)** | 20대 전반, 특히 여성 | 릴스 + 카드뉴스 캐러셀 | 🟢 2순위 |
| **TikTok** | 신입생·1~2학년 | 짧은 영상 | 🟡 3순위 |
| 한국인 유학생 커뮤니티 (카톡방·라인·디시 해외대학갤) | 초기 시드 유저 | 텍스트 + 링크 | 🟢 **지금 당장** |

### 🔴 X가 1순위인 이유 — 그리고 **계정을 지금 만들어야 하는 이유**
일본 대학 신입생은 **2~3월에 X에서 「#春から明治」 같은 태그로 동기를 찾는다.** 매년 반복되는 연례행사다.
- 그 시기에 계정이 **이미 있고 팔로워가 어느 정도 쌓여 있어야** 그 흐름에 올라탈 수 있다
- 2월에 계정을 새로 파면 아무도 안 본다. **팔로워를 쌓는 데만 2~3개월**이 든다
- 👉 **계정 개설은 11월 초**가 마지노선이다. 이건 코드보다 먼저다

### 계정 구성
초기엔 **1개로 통합**한다. 준희 혼자 운영이라 계정을 나누면 둘 다 죽는다.
- 표시 이름: `大学の森` (앱 이름과 동일 — 검색 일치가 중요)
- 성격: 앱 공지가 아니라 **콘텐츠 계정**. 공지는 전체의 10% 이하
- 성장하면 분리를 검토 (공식 / 콘텐츠)

### 2-1. 🔑 아이디(핸들)를 뭘로 할 것인가 — 준희가 정할 것은 이것 하나다

**「아이디」 = `@` 뒤에 붙는 영문 주소**다. 인스타에서는 `instagram.com/○○○`의 ○○○, X에서는 `@○○○`.
표시 이름(`大学の森`)과는 별개로, **영문·숫자·언더스코어만** 쓸 수 있다.

| 후보 | 길이 | 평 |
|---|---|---|
| **`daigakunomori`** | 13자 | 🟢 **권장.** 앱 이름을 그대로 로마자로 읽은 것. 입으로 말하기 쉽고 타이핑도 쉽다 |
| `daigaku_no_mori` | 15자 | 🟢 구분이 잘 보인다. X 아이디 상한이 **정확히 15자**라 딱 맞는다 |
| `daigakunomori_jp` | 16자 | 🟡 위가 이미 선점됐을 때. **X에서는 16자라 못 쓴다** |
| `univ_forest` | 11자 | 🔴 영어라 일본 학생이 앱 이름과 연결을 못 한다. 검색 유입이 죽는다 |

**정하는 기준은 하나다 — 앱 이름으로 검색했을 때 나와야 한다.**
카드뉴스를 본 사람이 「大学の森」를 검색 → 계정이 뜨고 → 앱으로 간다. 이 연결이 끊기면 전부 무의미하다.

**🟢 준희가 할 일 (순서대로, 15분)**
1. 인스타에서 `daigakunomori`가 비었는지 확인 → 비었으면 그걸로 만든다
2. 선점돼 있으면 `daigaku_no_mori` → 그것도 막히면 `daigakunomori_jp`
3. 🔑 **X도 같은 아이디로 같이 만든다.** 지금 안 쓸 거라도 **선점만 해둔다**
   (나중에 남이 가져가면 브랜드가 쪼개진다. 계정 만드는 건 공짜다)
4. 프로필에 넣을 것: 앱 설명 1줄 + **App Store 링크** (심사 승인 후)
5. 아이디가 정해지면 알려줄 것 → 앱 안 어디에 노출할지(설정 화면 등)를 같이 정한다

> ⚠️ 아이디는 나중에 바꿀 수 있지만, **바꾸면 그동안의 링크가 전부 깨진다.** 처음에 정하는 게 좋다.

## 3. 제작 — 릴스보다 카드뉴스가 먼저다

준희가 혼자 만든다면 **시간이 가장 비싼 자원**이다. ROI 순서를 지키자.

| 형식 | 1개 제작 시간 | 양산성 | 평 |
|---|---|---|---|
| **카드뉴스 (정지 이미지)** | 템플릿 후 5~10분 | 🟢 매우 높음 | **여기부터.** 템플릿 1개 만들면 글만 갈아끼운다 |
| 짧은 영상 (텍스트+BGM) | 20~30분 | 🟡 중간 | 카드뉴스가 돌기 시작하면 |
| 본격 릴스 (촬영·편집) | 2시간+ | 🔴 낮음 | 지금 할 일이 아니다 |

### 카드뉴스 템플릿 (1장 구성)
```
┌─────────────────────┐
│  大学の森            │ ← 작게, 상단
│                      │
│  「駿河台の喫煙所、   │ ← 글 제목 (크게)
│   結局どこが一番マシ？」│
│                      │
│  💬 23  👍 41        │ ← 반응 수 (사람이 있다는 신호)
│                      │
│  大学の森で見る →     │ ← 유도
└─────────────────────┘
```
- **반응 수를 넣는 게 핵심이다.** "사람이 있는 앱"이라는 증거가 된다
- 2장짜리로 만들면 1장=제목, 2장=베스트 댓글. 댓글이 재밌으면 전환이 더 높다

### 3-3. 🆕 카드 스타일 v2 — 준희 예시 4장에서 뽑은 규칙 (2026-11-13)

> 준희: 「AI 느낌이 나더라도 디자인이 밤티(촌스러움)여서 나는 게 아니라 **고퀄 느낌**이면 된다. 직접 찍은 사진은 없어도 된다.」
> 예시(한국 인스타 카드 4장 — 이미지는 저작권상 저장소에 두지 않음): ① 노랑·흰 오리 캐릭터 9칸 「어디까지 가능?」 ② 공책 배경 핑크/블루 2단 비교 「딸 아빠상 vs 아들 아빠상」 ③ 광고판 액자 속 실사풍 남녀 밸런스 게임 「버튼을 누른다/안 누른다」 ④ 실사풍 인물 1~7 순위 「어디부터?」

| # | 규칙 | 예시에서 |
|---|---|---|
| ① | **사람·캐릭터가 주인공** — 얼굴 표정이 감정을 전달. 일러스트(웹툰·치비)든 실사풍이든 **고퀄**이면 된다. 소품 일러스트(시계·침대)만으로는 약하다 | 전부 |
| ② | **밝고 채도 높은 파스텔** — 흰/아이보리 바탕 + 핑크·하늘·노랑. 비교는 **핑크 vs 블루**, 선택지는 **A=빨강 원 / B=파랑 원**. 칙칙한 녹색·오렌지 탈락 | ①②③④ |
| ③ | **굵고 둥근 고딕 제목 + 키워드만 색·형광펜** — 제목 중 1~2단어를 빨강·파랑으로, 핵심어 뒤에 노란 하이라이트 박스 | ①②④ |
| ④ | **제목 3단 위계** — 큰 질문 / 조건 한 줄 / **빨간 반전 한 줄**(「ただし、〜」) | ③ |
| ⑤ | **번호 그리드** — 1~7, 1~9 칸마다 같은 구도·다른 상황. 숫자는 색 원 안에 | ①②④ |
| ⑥ | **프레임 연출** — 광고판·공책·말풍선 같은 「물체 안의 카드」로 입체감 | ②③ |
| ⑦ | **마지막 줄은 댓글 유도 질문** — 「みんなはどう思う？」 | ② |
| ⑧ | 포맷: **「どこまでOK？」「どこからが〇〇？」 랭킹** · **2열 비교** · **究極の2択** — 셋 다 댓글이 폭발하는 형식 | 전부 |

#### 예시 ⑤ — 뉴스형 「キャンパス速報」 (11/13, 한국어 일본 화제 계정 omoro.roro 피드)

- 「사람이 만든」 느낌이 가장 강한 포맷이다 — 꾸밈이 없고 사진이 일한다. **MARKETING §1의 「우리 앱에서 화제가 된 글」 카드에 그대로 맞는다**(3줄째 = 앱 베스트 댓글 인용)
- 🔴 그 계정은 남의 사진·뉴스 사진을 쓴다 → 우리는 **준희 사진·AI 생성 이미지만**
- 템플릿: `scripts/cardnews/news.mjs` (샘플 `samples/news-sample.json`). 1줄 12자 이내
- 계정 성격도 참고: 「일본 화제를 매일 한국어로」 → 우리 일본어 계정과 별개로, **한국인 유학생·유학 준비생용 한국어 시리즈**를 나중에 검토할 만하다(📌)

**제작 방식이 바뀐다**: 이 예시들은 **카드 전체를 이미지 모델 한 번으로** 만든 것(그림+글자 일체). → 일본어 글자를 잘 쓰는 모델(**Nano Banana Pro · GPT Image**)로 카드 통째 생성 → 글자 틀린 곳만 Canva에서 덮어 고친다. Higgsfield 3일 체험에 두 모델이 다 들어 있다. (Recraft+Canva 레이아웃안은 보류)
