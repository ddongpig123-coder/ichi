## 6. 쪽지 입력 시 자판이 입력창을 가림 — ✅ 원인 확정

- **파일**: `app/(tabs)/messages/[chatId].tsx:103`
- **원인**: `keyboardVerticalOffset={90}`이 **하드코딩**. 기기별 헤더·세이프에어리어 높이가 달라서
  기종에 따라 입력창이 자판에 먹힌다. 안드로이드는 `behavior={undefined}`라 아예 보정이 없다.
- **수정**: `useSafeAreaInsets()` + `useHeaderHeight()`로 실제 값 계산, 안드로이드는 `behavior="height"` 또는
  `android:windowSoftInputMode` 확인. 입력 후 자동 스크롤도 같이.
- **배포**: OTA
- ✅ **S1 결과 (2026-10-29)**: offset = `useHeaderHeight()`(상단 safe area 포함). 하단 safe area는 탭바가 가지므로 따로 안 더한다.
  안드로이드는 SDK 57 edge-to-edge라 OS가 리사이즈하지 않음 → `behavior="padding"`(iOS와 같은 계산식).
  자판이 열리면 최신 메시지로 자동 스크롤. 🟡 **웹에는 소프트 자판이 없어 실기기 확인 필요**

## 10. 홈화면 위젯 (시간표) — 1.2로

- 준희 제안: "시간표 스샷 찍어서 배경화면 하는 사람이 많으니 위젯이 있으면 좋겠다" — **좋은 관찰**이다.
  배경화면용 스샷은 **실제 수요가 이미 증명된 행동**이라 위젯 전환율이 높다.
- **문제**: iOS 위젯(WidgetKit)·안드로이드 위젯은 **네이티브 코드**다. Expo에서는 config plugin + **재빌드** 필요.
  OTA로 못 낸다.
- **단계적 접근 제안**:
  1. **1.1 (OTA 가능)**: 시간표 화면에 **"이미지로 저장" 버튼** — 지금 하는 행동(스샷)을 깔끔하게.
     배경화면용 비율·투명 배경·다크 버전까지 주면 그대로 배경화면이 된다. `react-native-view-shot` 사용
  2. **1.2 (재빌드)**: 진짜 위젯 (`expo-apple-targets` 등)
- **배포**: 1단계 OTA / 2단계 재빌드
